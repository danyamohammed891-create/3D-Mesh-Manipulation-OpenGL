Project Overview

This project demonstrates basic computer graphics concepts using OpenGL and GLUT.

Features
3D colored cube rendering
Camera implementation using gluLookAt()
Translation, rotation, and scaling transformations
Real-time animation
Keyboard controls
Depth testing     
| Key   | Function         |
| ----- | ---------------- |
| W     | Move Up          |
| S     | Move Down        |
| A     | Move Left        |
| D     | Move Right       |
| T     | Scale Up         |
| G     | Scale Down       |
| Space | Toggle Animation |
| ESC   | Exit Program     |
Technologies Used
C++
OpenGL
GLUT
